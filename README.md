# Calculadora de Carbono

Um aplicativo simples em HTML, CSS e JavaScript (vanilla) para estimar o impacto ambiental de viagens.

## Visão Geral do Projeto

Este projeto calcula a pegada de carbono de uma viagem com base em entradas do usuário, como:

- distância percorrida
- modo de transporte
- número de viajantes
- viagem só de ida ou ida e volta

Usa HTML para a estrutura, CSS para o estilo e JavaScript para a lógica de cálculo.

## Funcionalidades

- Calculadora de impacto de viagem
- Interface responsiva e fácil de usar
- Estimativa instantânea de emissões em equivalente CO₂
- Funciona totalmente no navegador, sem backend

## Estrutura do Projeto

- `index.html` — página principal do aplicativo
- `css/styles.css` — estilos do aplicativo
- `js/` — lógica JavaScript para cálculos e comportamento da interface

## Como Usar

1. Abra `index.html` no navegador
2. Insira os detalhes da viagem (distância, modo, número de viajantes)
3. Selecione ida ou ida e volta
4. Clique no botão de calcular
5. Veja a estimativa do impacto ambiental

## Por que Isso é Importante

Viagens são uma fonte significativa de emissões de gases de efeito estufa. Esta calculadora ajuda o usuário a entender como diferentes escolhas de transporte e comportamento afetam o planeta e a tomar decisões mais sustentáveis.
